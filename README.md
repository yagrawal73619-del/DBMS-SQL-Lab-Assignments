DBMS & SQL Lab Assignments
A collection of Database Management System (DBMS) and SQL lab assignments completed and documented as part of my B.Tech Computer Science and Engineering coursework.

About This Repository
This repository contains SQL practical assignments covering fundamental and advanced database concepts. It is maintained as a learning resource to practice SQL queries, database operations, and DBMS concepts.

Repository Contents

The repository includes 15 assignment folders:
- Assignment 01 – Assignment 15
- SQL solution files
- Expected output files
- Practical query implementations

Technologies Used
- SQL
- MySQL
- SQLite
- PostgreSQL (where required)

Topics Covered
- SQL Basics
- Data Definition Language (DDL)
- Data Manipulation Language (DML)
- Data Query Language (DQL)
- Database Tables
- Constraints
- Joins
- Aggregate Functions
- Subqueries
- Database Operations

How to Use
1. Clone or download this repository.
2. Open the required assignment folder.
3. Read the SQL solution file.
4. Execute queries in the appropriate database environment.
5. Check the corresponding output file.

Learning Objectives
- Understand database concepts.
- Practice SQL queries.
- Improve database management skills.
- Gain practical experience with relational databases.
